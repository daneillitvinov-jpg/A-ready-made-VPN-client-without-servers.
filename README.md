## О проекте

AERIS — desktop-клиент для небольшого VPN-сервиса: для себя, друзей и пользователей по приглашению. Основная идея — оставить на главном экране только подключение и состояние сети, а управление аккаунтами и настройку сервера вынести отдельно.

Сейчас это рабочий прототип Windows-клиента. Он управляет официальной службой WireGuard, хранит локальные аккаунты и позволяет создателю выдавать Premium вручную. Общая серверная авторизация, оплата и ограничение скорости — следующий этап разработки.

## Что уже работает

- Собственная тёмная рамка окна: перемещение, сворачивание и разворачивание.
- Вход и регистрация, подтверждение пароля, показ и запоминание пароля.
- Первый запуск с созданием аккаунта владельца.
- Роли Basic, Premium и создателя; выдача Premium в подарок или после подтверждения оплаты.
- Импорт профиля WireGuard, запуск и остановка туннеля.
- Проверка свежего handshake, без подмены его проверкой доступа в интернет.
- Шифрование профиля и сохранённых данных входа через Windows DPAPI.

## Запуск приложения

В комплекте находится `app/AERIS-VPN.exe`. Для него не нужен установленный Python.

1. Запустить приложение и создать аккаунт владельца при первом запуске.
2. Установить [официальный WireGuard](https://www.wireguard.com/install/).
3. Получить конфигурацию своего VPN-сервера и добавить её в настройках подключения.
4. Нажать «Подключить». Windows запросит права администратора для управления службой.

Приложение не включает готовый VPN-сервер или подписку. Закрытие окна оставляет туннель работающим; для остановки используется кнопка «Отключить».

## Запуск из исходников

Нужны Windows x64 и Python 3.14 с Tkinter.

```powershell
python src/app.py
```

Основное приложение использует стандартную библиотеку Python. Для сборки и форматирования:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe scripts/test.py
.\scripts\build.ps1
```

Готовый EXE появится в `app/`. Инструкция по публикации — [RELEASING.md](docs/RELEASING.md).

## Basic и Premium

Premium выдаётся вручную: друзьям бесплатно или после подтверждения оплаты. В текущей версии это локальный статус аккаунта, а не действующая система подписок.

План для Basic — ограничение до 50% от скорости, измеренной до подключения VPN, отдельно для загрузки и отдачи. Само ограничение должно применяться на сервере. Замер и серверные правила пока не реализованы. Premium снимает тарифный лимит, но не ограничения интернет-провайдера, маршрута и VPS.

## Ограничения

Аккаунты пока не синхронизируются между компьютерами. Локальный администратор может изменить базу, поэтому такую авторизацию нельзя использовать как защиту платного сервиса. Блокировка в интерфейсе не отзывает ключ на сервере и не останавливает уже активный туннель.

Поддерживается один профиль WireGuard и один сервер. Нет автопереподключения, трея, цифровой подписи EXE и мобильных клиентов. Сквозное VPN-подключение и скорость на реальном сервере ещё не подтверждены. Подробнее: [архитектура и хранение данных](docs/ARCHITECTURE.md).

## Проверки

Тесты проверяют вход, права владельца, выдачу Premium, блокировку, первый запуск, валидацию VPN-профилей и шифрование DPAPI. GitHub Actions запускает их на Windows. Это проверки кода; они не заменяют сетевые испытания с реальным VPN-сервером.
